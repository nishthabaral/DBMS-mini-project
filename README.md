# Pharmacy Management System

A full-stack project using Node.js, MySQL, and JavaScript.

## Features
- Manage medicines
- Place & track orders
- Supplier management
- Search functionality

## Tech Stack
- Node.js (v18.x)
- Express.js (v4.x)
- MySQL (v8.x)
- HTML5
- CSS3
- JavaScript (ES6)

- ## Environment
- OS: Windows 11
- MySQL Workbench
- VS Code
